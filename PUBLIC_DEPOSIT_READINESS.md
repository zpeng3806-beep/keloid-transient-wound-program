# Public deposit readiness

Remaining mechanical steps only:

1. Select the repository host (GitHub and/or Zenodo).
2. Add an author-approved open-source license or retain the current no-license status deliberately.
3. Create the repository or deposition record and upload this exact clean archive.
4. Record the generated permanent URL/DOI in the manuscript and metadata, if available before acceptance.
5. Verify the hosted archive checksum against `CHECKSUMS.sha256`.

No scientific editing, analysis rerun or result change is required.
